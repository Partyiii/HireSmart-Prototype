# HireSmart Prototype

An automated hiring portal prototype designed to streamline the recruitment process. This project bridges the gap between candidates and the HR team by offering a seamless, mobile-friendly application experience, automated backend tracking, and a real-time dashboard for HR.

## 🛠️ Tech Stack Used
*   **Frontend (Website):** Notion
*   **Application Form:** Google Forms
*   **Database:** Google Sheets
*   **Automation:** Google Apps Script
*   **Design & Prompts:** Claude AI / Gemini

## ⚙️ How it Works
1.  Candidates visit the Notion Careers Page and click "Apply Now".
2.  They fill out the Google Form with their details and resume link.
3.  The data is instantly saved into a Google Sheet database.
4.  Google Apps Script triggers in the background and sends an automated acknowledgement email to the candidate.
5.  HR can track the candidate's progress (Applied -> Shortlisted -> Hired) using the Notion Kanban Board dashboard.

## ✨ Core Features
*   Mobile-friendly Careers Page with FAQs.
*   Instant Auto-Email generation.
*   Visual Hiring Funnel (Kanban Board).
*   Dummy AI Resume Scoring for candidate ranking.
